# 同程价格类归因标准 Case

> **用途**：`eval.py` 自校验用，每次归因逻辑更新后运行，验证输出是否与预期一致。
>
> **字段说明**：原始 Excel 列名：备注 / Q划线价——同质化房型 / 划线价（竞品）/ Q支付价——同质化房型 / 到手价（竞品）/ 促销明细（竞品）。以下 case 中 Q促销/E促销 为促销内容简写，E侧促销对应系统竞品促销分行表。
>
> **V1校验**：所有 case 满足 |划线价 - (支付价 + 促销总额)| ≤ 1.0。

## Case 01 — 底价：E划线价更低（E含商促）

**输入**
```
备注: 可对比-lose-同质化lose
Q划线价——同质化房型: 500 / 划线价（竞品）: 440
Q支付价——同质化房型: 480 / 到手价（竞品）: 400
Q促销: 房费立减-¥20
E促销: 平台优惠(定价)-¥20 / 早鸟优惠(商促)-¥20
```

**过程变量**
```
|Q划线价——同质化房型 - 划线价（竞品）| = 60 > 0.1  →  底价路径
划线价（竞品）(440) < Q划线价——同质化房型(500)  →  E划线价更低
e_shangcu_total = 20 > 0  →  E含商促
```

**预期输出**
```
一级_AI: 价格lose / 二级_AI: 底价 / 三级_AI: E划线价更低 / 四级_AI: E含商促
是否需要人工校验: 否
```
