# 字段全量定义

> **同步规则**：`field_map.json`（本目录）与本文档必须同步修改。
> 修改任一字段名时，需同时更新：
> 1. `field_map.json`（运行时映射，机器读取）
> 2. 本文档（全量定义，人类参考）

---

## 一、原始字段（输入层，由用户 Excel 提供）

> 列名可在 `field_map.json` 中修改，无需改动代码。

### 1.1 共用字段（同程 / 携程均有）

| code key         | 当前 Excel 列名          | 说明                                      | 读取方      |
|------------------|------------------------|------------------------------------------|------------|
| `im_text`        | 客服与用户沟通记录         | IM对话全文，IM归因唯一分析对象                    | IM归因       |
| `kf_note`        | 客服判断场景              | 一级路由主来源（库存lose/无法归因/用户误解/价格lose）；IM归因辅助输入 | 促销校验、归因、IM归因 |
| `compare_platform`| 比价平台                | 平台合法性校验（携程/美团/飞猪/同程）            | 促销校验、归因 |
| `q_list_price`   | Q划线价——同质化房型       | Q 侧划线价，V1 金额校验 + V3 一致性校验         | 促销校验、归因 |
| `q_pay_price`    | Q到手价——同质化房型       | Q 侧到手价，V1 金额校验 + V3 一致性校验         | 促销校验、归因 |
| `c_list_price`   | 划线价（竞品）            | 竞品侧划线价，V1 金额校验                       | 促销校验、归因 |
| `c_pay_price`    | 到手价（竞品）            | 竞品侧支付价，V1 金额校验 + V3 一致性校验         | 促销校验、归因 |
| `q_promo_detail` | Q优惠明细                | Q 侧促销明细文本，解析后写入 Q促销分行表           | 促销校验      |
| `c_promo_detail` | 促销明细（竞品）          | 竞品侧促销明细文本，解析后写入 竞品促销分行表        | 促销校验      |
| `case_no`        | case编号                | case 唯一标识，关联 fallback 键（工单号为空时使用） | 促销校验、归因、IM归因 |
| `order_no`       | 工单号                  | 关联主键，优先于 case编号；为空时 fallback 到 case编号 | 促销校验、归因、IM归因 |

### 1.2 平台专用字段

#### 同程（tongcheng）

| code key       | 当前 Excel 列名    | 说明                                   | 读取方 |
|----------------|-----------------|---------------------------------------|--------|
| `multi_points` | 是否多倍积分酒店   | 积分 lose 四级判断；空时触发人工校验         | 归因    |

#### 携程（xiecheng）

| code key     | 当前 Excel 列名      | 说明                                      | 读取方 |
|--------------|-------------------|------------------------------------------|--------|
| `roomid_q`   | 同质化房型roomid     | Q 侧 roomid，与 roomid_c 相同时进入同质化路径 | 归因    |
| `roomid_c`   | CRoomID           | 竞品侧 roomid                              | 归因    |
| `is_fenxiao` | 是否分销            | 未分销→报价未接入；分销+未露出→报价未露出        | 归因    |
| `is_louchu`  | 是否露出            | 报价未露出路由                              | 归因    |
| `lingjuan`   | 领用券情况          | 平券类四级归因（定价券lose/无对标券/未领券等）   | 归因    |

## 二、过程字段（写入层，模块产出，列名固定不可配置）

### 2.1 IM归因模块产出（写入主数据文件 Sheet1）

| 列名             | 写入方   | 读取方 | 说明                            |
|-----------------|---------|--------|-------------------------------|
| im-归因结果-AI   | IM归因   | 归因    | IM 归因结果（用户误解子类/库存路由等） |
| im-归因说明-AI   | IM归因   | 归因    | IM 归因说明（触发"新发现场景"检测）   |

### 2.2 归因模块产出（写入主数据文件 Sheet1）

| 列名              | 说明                                            |
|-----------------|------------------------------------------------|
| 一级_AI          | 异常 / 无法归因 / 库存lose / 用户误解 / 价格lose / 校验失败 |
| 二级_AI          | 二级分类                                         |
| 三级_AI          | 三级分类（多个时用中文逗号分隔）                       |
| 四级_AI          | 四级分类                                         |
| 五级_AI          | 五级分类（暂保留空）                                |
| 归因备注          | 异常说明 / V3 错误 / 比价平台信息 / 人工校验原因        |
| 归因平台_AI       | 本次运行平台                                      |
| price_rule_set_AI| 本次使用的价格规则集合                              |
| promo_code_set_AI| 本次使用的促销码表集合                              |
| 是否需要人工校验   | 有校验问题时写「是」，否则空                          |
| 人工校验内容       | V1/V2 错误说明 + 路由冲突 + 兜底验证原因             |

## 三、促销数据文件字段（促销校验模块产出，固定 schema）

| 促销类型2级  | 码表匹配结果        |
| 促销类型3级  | 码表匹配结果        |
| 特殊类型     | 黑鲸优惠 / 大额券 / 常规平台券 等 |
| 是否十亿补贴 | 是 / 否           |
